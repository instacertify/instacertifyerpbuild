# Roles & Permissions

## IC Admin
- Create/edit/delete all IC DocTypes
- Download Excel from Lead, Quotation, Project, Test Request, Asset, Lab lists
- Manage IC Settings, Services, Consultants
- Create IC HR users/profiles and employee joining letters
- Receive quote-accepted notifications

## IC All Ops Manager
- View all records across sales and operations
- Submit / authorise quotations
- Excel export
- Cannot delete master data (by default)

## IC Sales Person
- Create and edit quotations (including from templates)
- See quotations assigned to them or created by them
- See leads assigned to them
- Progress on projects they closed (sales_person filter)
- Customer history for assigned customers (quotes, deliverables)
- Use Lab library when building testing quotes
- Cannot see other sales persons’ pipelines

## IC Operations Manager
- Oversee projects: progress remarks, working hours, credentials, incidents
- Customer document requests and verification
- Test request / sample status updates
- Share customer project portal + login credentials
- Read quotations (no create)

## IC Customer Manager
- Customer-facing project coordination
- Share project portal links and customer login credentials
- View/update project messages, document requests, invoices

## IC HR
- Employee profiles
- Support salary slips / attendance / holiday calendar access via ERPNext HRMS
